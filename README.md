### Student Management System
**Technologies:** Python, Object-Oriented Programming (OOP)

→ Developed a menu-driven application to manage student records, including adding, searching, updating, displaying, and deleting student details.

→ Implemented automated calculation of total marks, average, grades, pass/fail results, and class topper identification.

→ Utilized classes, objects, constructors, methods, lists, and dictionaries for structured student record management.

→ Implemented input validation and exception handling to manage invalid entries and ensure accurate marks processing.
